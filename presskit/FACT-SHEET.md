## At a glance

- **Eight boot profiles** — CLEAN (max compatibility), XMS Gaming (default),
  EMS Gaming, CD-ROM Gaming, Windows 3.x, Diagnostics, Safe Mode, Command Prompt.
- **Original text-mode suite** — main menu, game launcher, memory-profile
  switcher, sound setup, hardware diagnostics, config editor, rescue tools,
  file manager, disk doctor, benchmark, text editor, help reader, minigames.
- **Installer + rescue disk** — a single 1.44 MB floppy is both the installer's
  first disk and an emergency boot/rescue disk.
- **Boot experience** — a rebranded kernel and an animated fortress-keep splash;
  the machine boots onto CASTALIA and nothing else.
- **No Microsoft material** — zero MS-DOS code, text, or branding.

## Naming & identity

- Always written **CASTALIA DOS** (all-caps in banners; "Castalia DOS" in prose).
- Signature accent colour: **amber** (VGA yellow) on **Mediterranean blue**.
- Mark: a three-tower **fortress keep** rendered entirely in CP437 text glyphs.
- Version codenames are **fortress towns of Valencia & Castellón** (Almenara,
  Peñíscola, Morella, Tombatossals, Montornés).
