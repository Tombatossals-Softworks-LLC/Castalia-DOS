## Long (≈150 words)

CASTALIA DOS is a practical, beautiful, game-focused DOS-compatible operating
environment for real retro hardware — 386SX, 386DX, 486, and early Pentium
machines with limited RAM, VGA, IDE/CompactFlash storage, and Sound Blaster
audio. It is built on the open-source FreeDOS kernel and shell and wraps them in
an original suite of Castalia work: eight boot profiles that maximise
conventional memory for the task at hand, a game launcher that unloads itself
before a game runs, sound and memory configuration, hardware diagnostics, an
installer, a rescue disk, a help system, and a dignified 80×25 text-mode
identity drawn from the stone fortresses of the Valencian coast. When a Castalia
machine boots, it opens onto Castalia and nothing else. It behaves like DOS —
because DOS games expect DOS — while making everything around DOS better.
Original Castalia code and branding are MIT-licensed; FreeDOS components remain
GPLv2+ with source. CASTALIA DOS contains no Microsoft code, text, or branding.

## Style notes for writers

- The product name is **CASTALIA DOS** — all-caps in headings/banners, or
  "Castalia DOS" in running prose. Never "Castalia OS" or "CastaliaDOS".
- It is a **DOS-compatible operating environment**, not "an operating system"
  in the kernel-authoring sense and not "an MS-DOS clone."
- Compatibility framing is fine as plain description ("MS-DOS 6.22-compatible
  behavior"); it is **not** an MS-DOS product and uses no Microsoft branding.
- The flagship is the **386SX Edition**; the current design target is
  **1.0 "Tombatossals"**.
